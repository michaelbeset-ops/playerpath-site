# Schermafbeeldingen voor de site

Zet hier je screenshots neer met **precies deze bestandsnamen**. Ze verschijnen
vanzelf op de site; je hoeft geen code aan te passen. Ontbreekt een bestand, dan
toont de site de nagebouwde versie.

| Bestandsnaam | Scherm in het platform | Formaat | Waar op de site |
|---|---|---|---|
| `dashboard.png` | `/dashboard` | desktop | Hero, bovenaan |
| `trainingen.png` | `/trainings` | desktop | Blok "Maak inschrijven eenvoudig" |
| `betalingen.png` | `/payments` | desktop | Blok "Verwerk betalingen zonder gedoe" |
| `inschrijven-mobiel.png` | `/inschrijven/{school}` | mobiel | Telefoon naast de trainingen |
| `facturen-mobiel.png` | ouder: "Mijn facturen" | mobiel | Telefoon naast de betalingen |
| `speler-1.jpg` t/m `speler-4.jpg` | portretfoto van een speler | staand | Op de vier spelerskaarten |

## Zo maak je ze scherp (Chrome)

**Desktop**
1. Open het scherm, druk `F12`, dan `Ctrl + Shift + M`.
2. Kies bovenaan *Responsive*, zet de maat op **1440 × 900**.
3. Menu met drie puntjes → *Add device pixel ratio* → zet op **2**.
4. `Ctrl + Shift + P`, typ `screenshot`, kies **Capture screenshot**.

**Mobiel**
1. Zelfde stappen, maar kies het apparaat **iPhone 14 Pro Max** of **iPhone 12 Pro**.
2. **Capture screenshot**.

## Voor je afdrukt

- Haal de oranje balk "Je kijkt naar voorbeelddata" weg: rechtsklik erop →
  *Inspecteren* → rechtsklik op het gemarkeerde element → *Delete element*.
  **Klik niet op "Voorbeelddata verwijderen"**, dat wist je demo-data.
- Sluit de kaart "Je school draait".
- Gebruik de voorbeeldschool, nooit echte kinderen.
- Voor de spelersfoto's: alleen foto's van je eigen spelers, met schriftelijke
  toestemming van de ouders. Geen stockfoto's: een licentie dekt het gebruik van
  de foto, maar niet het portretrecht van de persoon erop.
- Zorg dat het hoofd in de **bovenste helft** van de foto zit. De kaart snijdt
  vanaf de bovenkant uit; staat iemand mooi in het midden, dan valt zijn hoofd
  er net buiten.
